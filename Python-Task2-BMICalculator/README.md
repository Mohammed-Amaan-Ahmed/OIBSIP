\## Project Objective



The objective of this project is to build a BMI Calculator that calculates Body Mass Index from a user's weight and height, classifies the result according to standard BMI ranges, stores historical records, and provides a graphical BMI trend.



\## Features



\### BMI Calculation



\- Accepts weight in kilograms

\- Accepts height in meters

\- Calculates BMI using:
